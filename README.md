# Passion Fruit Boba Tea Recipe

A simple one-page recipe site for Boba Bash. It shows how to make passion fruit boba tea at home, with a cute little cup character named Pearl.

## What's on the page

- Ingredients list
- Step-by-step recipe
- A few tips
- Pearl, a cup character drawn with just CSS

## Built with

- HTML
- CSS

No frameworks and no JavaScript.

## Files

- `index.html` - the page
- `style.css` - the styling and the character
